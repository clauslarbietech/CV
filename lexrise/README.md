# LexRise

A web app to support people with dyslexia through:

- **Accomplishments** — real-world stories of people with dyslexia
- **Font Lab** — Lexend, OpenDyslexic, size, spacing, and contrast controls
- **Games** — phonics unscramble, b/d/p/q letter flip, nonsense decoding, scramble myth-bust
- **Research** — evidence notes and curated external phonics tools (Nessy, Starfall, Nonsense!, and more)

## Run locally

```bash
cd lexrise
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

LexRise is an educational practice tool, not a medical diagnosis product. Font preferences vary; research often finds letter/word spacing helps more than specialty letter shapes alone.
